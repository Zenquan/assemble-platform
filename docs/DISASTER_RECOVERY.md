## 1. 需求共识

### 目标

把「容灾」这一基础设施密集的方向，收敛为一份**可执行的部署层 checklist**，作为上线清单（方案第 10 章）的容灾验收依据。代码层前置件（优雅停机、readiness 摘流、健康池 failover、子进程自愈）已由 `HA.md` 方向落地，本方向不再新建代码，只把「主从 / 备份 / 多活 / 演练」的部署要求与验收口径写清楚。

### 范围

| 维度 | 内容 |
|------|------|
| ✅ 做 | ① 容灾部署 checklist（数据备份 / 服务自愈 / 对象存储多活 / 恢复演练四块） |
| ✅ 做 | ② 对齐 `HA.md` 已落地的代码层自愈能力，标注「代码层已具备 / 部署层待接」 |
| ✅ 做 | ③ 文档同步（README 导航 + VERSIONING 进度） |
| ❌ 不做 | 不写代码、不新增 workspace 包 |
| ❌ 不做 | 不本地实现 MySQL 主从 / 对象存储多活 / K8s 编排（本机无 docker，属部署层交付物） |
| ❌ 不做 | 不做数据迁移（migration）脚本（当前 `storage` 仍是内存/文件降级仓储，接真库在后续版本） |

### 关键设计决策

| 决策 | 结论 | 理由 |
|------|------|------|
| 落地形态 | 只文档化，代码层不新建 | 容灾主体是基础设施（主从/多活/灾备演练），本机无 docker 无法本地验证；代码层自愈已由 HA 方向闭环 |
| 与 HA 的关系 | HA = 代码层前置件，容灾 = 部署层 checklist | 两个方向互补：HA 保证「单机自愈 + 摘流 failover」，容灾保证「跨机/跨区数据不丢」 |
| 存储现状 | `storage` 仍是降级仓储（内存/文件） | 接真库（MySQL）是后续版本（0.6+）的事，本方向只预留 checklist，不提前抽象 |

## 2. 部署层 checklist（上线清单 · 容灾部分）

> 标 ✅ 表示代码层前置件已由 `HA.md` 方向落地；标 ⬜ 表示部署层待接。

### 2.1 数据备份

| 项 | 要求 | 状态 |
|----|------|------|
| 数据库 | MySQL 主从 + 半同步复制，跨可用区 | ⬜ 部署层 |
| 备份策略 | 每日全量 + binlog 增量，支持 PITR 时间点恢复 | ⬜ 部署层 |
| RPO/RTO | RPO ≤ 15min、RTO ≤ 30min | ⬜ 部署层 |
| 对象存储 | glTF 资产多区冗余 + CDN 多源容灾 | ⬜ 部署层 |

### 2.2 服务自愈

| 项 | 要求 | 状态 |
|----|------|------|
| 优雅停机 | SIGTERM/SIGINT → drain → 退出（滚动发布不切断请求） | ✅ `@assemble/health` |
| 健康摘流 | `/healthz` liveness + `/readyz` readiness 分离 | ✅ `@assemble/health` |
| 上游 failover | 健康池多副本轮询 + 故障摘流 + 恢复入池 | ✅ gateway `UpstreamHealthPool` |
| 进程自愈 | 子进程异常退出指数退避重启（不再整体崩溃） | ✅ gateway `UpstreamSupervisor` |
| 副本配置 | `UPSTREAM_TARGETS` env 多副本/外部地址 | ✅ gateway `resolveUpstreams` |

### 2.3 机房级故障

| 项 | 要求 | 状态 |
|----|------|------|
| 双活/跨区 | 核心数据双活，非核心单区 + 快速恢复 | ⬜ 部署层 |
| 负载均衡 | 外部 LB 多副本分流 | ⬜ 部署层 |

### 2.4 恢复演练

| 项 | 要求 | 状态 |
|----|------|------|
| 演练频率 | 每季度容灾演练 | ⬜ 部署层 |
| Restore Drill | 备份真实还原验证（不演练=没备份） | ⬜ 部署层 |
| 演练记录 | 演练结果留痕（RPO/RTO 实测达标） | ⬜ 部署层 |

---

## 3. 验收标准（上线清单 · 容灾部分）

- [ ] 备份可真实还原（Restore Drill 通过）
- [ ] 服务故障：单副本故障不影响请求（健康池摘流 + failover，代码层已具备）
- [ ] 数据丢失：RPO ≤ 15min、RTO ≤ 30min（部署层待接真库后验证）
- [ ] 每季度容灾演练有记录、结果达标
