# SIM-PLATFORM 关键页设计稿（深色科技扁平 · 定稿）

> 前端 `apps/sim-platform` 的关键页**设计稿**，风格为**深色科技扁平化**（工业数字孪生大屏感）。落 Vue3 组件前以此为准。
> **高保真稿**：`apps/sim-platform/design/sim-platform-tech-mockup.html`（浏览器打开，内含两页 tab 切换 + 设计令牌），对照转组件。

## 1. 设计语言与令牌

- **风格**：深色科技扁平 —— 深蓝黑底 + 极淡网格衬底 + 高信息密度；纯扁平，无实感渐变/重阴影（仅 CTA 与激活态用一档线性渐变）。
- **配色令牌**（转 Vue3 时用 CSS 变量承接，见 HTML 内 token 区）：

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--bg` | `#0a111f` | 整页 / 应用底 |
| `--bg-2` | `#0c1422` | 左右栏面板底 |
| `--bg-3` | `#0d1626` | 卡片 / 行底 |
| `--line` | `#1c2740` | 描边 |
| `--blue` | `#1f6feb` | 主色-蓝 |
| `--cyan` | `#22d3ee` | 主色-青（CTA/激活态） |
| `--green` | `#34d399` | 就绪 / 无干涉 |
| `--amber` | `#fbbf24` | 待检修 / 预警 |
| `--red` | `#f43f5e` | **干涉命中 / 瓶颈** |
| `--ink` | `#e8eefc` | 正文主 |
| `--mute` | `#64748b` | 弱文 / 注释 |

- **渐变**：仅 `linear-gradient(90deg,#1f6feb,#22d3ee)` 用于 CTA 按钮与激活态填充。
- **数字**：一律等宽字体 `ui-monospace`，耗时带 `ms` 小注。
- **语义色约定**：就绪绿 / 待检修琥珀 / **干涉命中红**（命中即高亮并拦截装配）；装配中 / 选中 / 主操作走信息蓝青。
- 复用**算法层真实口径**：干涉数 `clearance-core.runFull().hits`、耗时 `elapsedMs`、剔除率 `broadCullRatio`（见 `docs/TESTING.md`）；三模式状态源 `AssemblyMode` in `@assemble/domain`。

## 2. 页面 A —— 产线选择页

```
顶栏：3D 徽标 + 平台名 + 大写副标 + 引擎在线徽标 + (导入模型 / 新建产线)
产线卡片列表（主 B1 + 副 B2）
  卡片 = 缩略代号区 + 名称 + 状态徽标(光晕圆点) + 描述(工位数/标准节拍)
        + 指标格(零部件 / 干涉预检 / 预检耗时) + 细进度线
        + 脚部 CTA「进入装配工作台」或「处理干涉」
```

**要点**
- 状态徽标 = 就绪`绿光晕圆点` / 待检修`琥珀光晕圆点`，对接产线健康。
- 指标格是**入口离线预检快照**：B1 干涉 0 → 可进入；B2 干涉 3 → 引导「处理干涉」。
- B2「干涉预检 3」数字走**红色告警**。

## 3. 页面 B —— 装配工作台（核心）

```
顶栏：产线名 + 大写副标 + 引擎实时 + 模式切换(自动|手动|回放) + (复位/导出报告)
左栏：零件/BOM 树（分组折叠；装配中=青高亮、命中=红点✕）；底部视口控制(轴测/剖切/隐藏/适配)
中栏：3D 装配视口（深色网格底 + 零件轴测占位 + 传送带）——左上角 STEP 07/18，右下 HUD 坐标轴，底部播放条
右栏：实时干涉红卡(置顶) + 装配步骤列表(当前高亮) + 节拍监测(瓶颈红) + 瓶颈提示
```

**要点**
- **三模式**驱动中栏视口（自动/手动/回放），对应 `SimEngine` 门面三大能力（`ARCHITECTURE.md` §2）。当前高亮"手动"。
- **实时干涉**（手动模式核心）：拖拽零件时前端 `queryInteractive()` BVH vs 单件检测，命中即：
  - 中栏视口出现**斜纹红框 `INTERFERENCE`** 高亮命中零件 + 青色吸附引导线；
  - 右栏置顶**红色告警卡** `shaft_2 ↔ bearing_1 · OBB-SAT 命中`；
  - 本次落位被拦截，不执行装配。
- **步骤列表**：右栏顺序步骤，当前执行步（STEP 07）青高亮；与 `AssemblyStep[]` 一一对应。
- **播放控制条**：上一/播放/下一 + 进度条(knob) + 等宽时间戳，用于自动与回放模式。
- **节拍监测**：右栏横向条形，工位超过标准节拍标红 = 瓶颈（直接复用 `taktCore` 输出），底部给瓶颈诊断文案。
- **BOM 树**：按组件分组（壳体/传动/电机…），反映 `AssemblyPart` 树。

## 4. 后续落地提示（0.2.x）

- 中栏视口区为 WebGL canvas 占位，实现时以 Babylon 经 `SimEngine` 门面替换静态占位；HUD（STEP/坐标轴/命中框）由引擎层提供状态驱动。
- 干涉告警、状态徽标、指标格、节拍均为**状态驱动的展示**；接口数据源自 `@assemble/domain` 类型，不 `any`（`CODE_STYLE.md`）。
- 色板直接抄 `apps/sim-platform/design/sim-platform-tech-mockup.html` 的 CSS 变量，勿临时改色造成跑偏。
- 有布局/风格调整先改此稿 + HTML，再改码（遵循 `assemble-platform-workflow` skill）。
