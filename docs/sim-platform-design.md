# SIM-PLATFORM 关键页设计稿（Workbuddy Mockup）

> 前端 `apps/sim-platform` 的关键页**线框稿**（Workbuddy 内嵌 mockup 确认稿）。落地 Vue3 组件前以此为准。
> 本文件为文字性说明；交互线框稿已通过 Workbuddy mockup 内嵌渲染（产线选择页 + 装配工作台）。

## 1. 设计目标与约束

- **风格**：扁平工业风，浅色主题（对齐宿主 IDE），无重阴影/渐变，信息密度高、克制用色。
- **语义色**：
  - 就绪 / 无干涉 → 绿；待检修 → 琥珀；**干涉命中 → 红**（命中即高亮并拦截装配）。
  - 装配中 / 选中 / 主操作 → 信息蓝。
- 复用**算法层真实口径**：干涉数来自 `clearance-core` 的 `runFull().hits`，耗时来自 `elapsedMs`，剔除率来自 `broadCullRatio`（见 `docs/TESTING.md`）。
- 三模式（自动 / 手动 / 回放）是工作台的状态源（`AssemblyMode` in `@assemble/domain`）。

## 2. 页面 A —— 产线选择页

**信息架构**
```
顶栏：品牌(3D) + 平台名 + 操作(新建产线/导入模型)
产线卡片列表（主产线 + 副产线…）
  卡片 = 缩略区(代号) + 名称 + 状态徽标 + 描述(工位数/标准节拍)
        + 指标格(零件数 / 干涉预检 / 预检耗时)
        + CTA「进入装配工作台」
```

**要点**
- 状态徽标：`● 就绪(绿)` / `● 待检修(琥珀)` —— 对接产线健康。
- 指标格是**入口处的一次离线预检快照**（离线 `runFull`），让用户在进工作台前就感知该产线当前是否干净；B2 显示 3 处干涉预警即引导用户进去处理。
- 每个指标卡：小字 label + 大数字，数字用 `Math.round()` 处理。

## 3. 页面 B —— 装配工作台（核心）

**信息架构（三栏）**
```
顶栏：产线名 + 状态 + 模式切换(自动|手动|回放) + 复位/导出报告
左栏：零件/BOM 树（分组折叠，标注「装配中」）；底部视口控制(轴测/剖切/隐藏/自适应)
中栏：3D 装配视口（Babylon，经 SimEngine 门面）——占位示意，左上角步骤计数，底部播放控制条
右栏：装配步骤列表（当前步骤高亮）+ 实时干涉告警卡片
```

**要点**
- **三模式**驱动中栏视口：自动=按步骤逐步装配；手动=用户拖拽装配（实时干涉）；回放=重放已记录装配。对应 `SimEngine` 门面三大能力（`ARCHITECTURE.md` §2）。
- **实时干涉**（手动模式核心）：拖拽零件时前端用 `queryInteractive` 做 BVH vs 单件检测，命中即：
  - 中栏视口对应零件**红色高亮**；
  - 右栏出现红色告警卡 `shaft_2 ↔ bearing_1 · OBB-SAT 命中，装配被拦截`；
  - 拦截该次放置（不落位），提示调整姿态。
- **步骤列表**：右侧顺序步骤，当前执行步骤信息蓝高亮；与 `AssemblyStep[]` 一一对应。
- **播放控制条**：上一/播放/下一 + 进度条 + 时间戳（用于自动与回放模式）。
- **BOM 树**：按组件分组（壳体/传动/电机…），反映 `AssemblyPart` 树；正在装配的零件标注信息蓝。

## 4. 后续落地提示（0.2.x）

- 工作台主视口区域为 WebGL canvas 占位；Vue 组件薄，逻辑下推 `stores/` + `engine/`（SimEngine 门面）。
- 干涉告警、状态徽标、指标格均为受状态驱动的展示；接口数据源自 `@assemble/domain` 类型，不 `any`（`CODE_STYLE.md`）。
- 本设计稿随 `apps/sim-platform` 的 0.2.x 实现演进；有布局调整先改此稿再改码（遵循 `assemble-platform-workflow` skill）。
